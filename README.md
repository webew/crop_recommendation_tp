# crop_recommendation_tp

Recommandation de culture agricole à partir du sol et du climat (jeu de données Crop recommendation).

## Prérequis

- Git
- uv

## Installation

```
git clone <adresse du dépôt>
cd crop_recommendation_tp
uv sync
```

`uv sync` crée l'environnement `.venv` et installe les versions enregistrées dans `uv.lock`.

## Configuration

Les paramètres du jeu de données et du découpage se trouvent dans `config/config.yaml`.
